# Flask Auth Dynamic Content

![Python](https://img.shields.io/badge/Python-3776AB?logo=python&logoColor=white) ![Flask](https://img.shields.io/badge/Flask-000000?logo=flask&logoColor=white) ![SQLite](https://img.shields.io/badge/SQLite-003B57?logo=sqlite&logoColor=white)

Documentação de um projeto de estudo de **aplicação Web com Flask**, voltado a autenticação de usuários, rotas protegidas e conteúdo dinâmico armazenado em SQLite.

## Estado do repositório

**A implementação ainda não está publicada.** Atualmente, este repositório contém somente o `README.md`. Os itens apresentados a seguir descrevem o escopo proposto, **não funcionalidades disponíveis para execução**.

## Objetivo

Praticar desenvolvimento web no servidor, com ênfase em autenticação, sessões, controle de acesso e integração com banco de dados.

## Funcionalidades planejadas

- Autenticação de usuários.
- Armazenamento de senhas com hash apropriado.
- Controle de sessões e acesso a páginas protegidas.
- Leitura e apresentação de conteúdo dinâmico armazenado em SQLite.

## Tecnologias previstas

- Python e Flask.
- SQLite.
- HTML5 e CSS3.

## Conceitos de estudo

- Rotas e ciclo de requisições HTTP.
- Autenticação e autorização.
- Proteção de credenciais e sessões.
- Consultas a banco de dados.
- Renderização de conteúdo dinâmico.
